# Implementation prompt

Continue task `<TASK_ID>` in scope `<PATHS>` with acceptance criteria `<CRITERIA>`. Follow the current UADOS workflow and applicable project rules.

Before acting, inspect the task, its dependencies, relevant decisions, current implementation and evidence. Start or refresh a session, read its Understanding Report and acknowledge its current hash. Verify required resources. Claim the task; major work must already have an independent approved plan.

Implement the smallest coherent change satisfying the task. Respect other contributors' ownership. If assumptions or scope change materially, document the change and obtain renewed plan review instead of continuing under an obsolete plan. Record consequential choices with problem, alternatives, evidence, reason and risk.

Run checks that actually test the changed behavior. Preserve outputs and explain what they establish and what they leave uncertain. Record the task result with its evidence. Do not call an unavailable or unexecuted check passing. Major work requires independent result approval for the current scoped content/evidence before completion.

If blocked, record the cause, evidence and concrete recovery action. Preserve failed approaches and lessons. At a stopping point, close the session with completed work, validation, unresolved gaps and the first action for a new contributor. Do not hand-edit generated state or log files.
