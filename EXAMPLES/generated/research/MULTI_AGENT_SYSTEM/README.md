# Multi-agent collaboration

UADOS coordinates contributors through durable tasks, scoped ownership, review records and session handovers. It does not need a particular model provider or orchestration service. The human or agent environment chooses how to start independent contributors; each contributor uses the same project record.

Read `roles.md` for responsibilities and `review_protocol.md` for adversarial review. A team can combine roles for routine work. Major work must have an independent reviewer who did not implement the reviewed change and uses a distinct recorded identity.

Before assigning work, make a task with a concrete outcome, relevant paths, risk and dependencies. Contributors inspect current context and claim their tasks. Keep parallel scopes disjoint where possible. Scope conflicts require coordination; a lease is a recorded ownership mechanism rather than an operating-system access restriction.

Communication that changes project direction must become a decision, task or note. A reviewer should leave an evidence-backed challenge instead of an untraceable approval in chat. Before a contributor leaves, close the session with current findings and a usable next step.

The team remains responsible for real independence. Creating two agent labels in one process does not satisfy the intent of adversarial review. Record reviewer role, inspected artifacts and assumptions challenged so a human can assess review quality.
