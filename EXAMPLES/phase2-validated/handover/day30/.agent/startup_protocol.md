# Agent startup protocol

Authority: [master workflow, section 1](../MASTER_AGENT_WORKFLOW.md#1-establish-context-before-action). This operational worksheet supports startup without replacing its gates.

Prepare a context packet with stable contributor label, client/runtime name if known, project root, recorded mode, intended task, policy version and current resource access. Inspect mode-detection evidence; distinguish a classification assumption from an observed resource. Read the task and dependencies before proposing parallel work.

The issued `PROJECT UNDERSTANDING REPORT` is the startup output. Verify its objective, phase, architecture, completed work, problems, risks, resource inventory and next actions against their files. Add explicit findings for missing data, unavailable services, resource constraints and unresolved assumptions. Do not fabricate capability or availability from a filename.

Record the exact issued report hash, acknowledge it and prepare the evidence-backed execution plan required for the task's protocol. Keep the report in the generated session register. If tracked state or governed documents change, use the master's refresh/acknowledgement procedure. Read [compatibility.md](compatibility.md) when the client cannot discover these instructions reliably.
